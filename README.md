
## 🚀 Cách dùng

1. Mở `index.html` bằng trình duyệt
2. Nhập tên thầy/cô → Click **Viết Lên Bảng**
3. Xem lời chúc viết phấn trên bảng đen
4. Chọn tiếp: Nhận Hoa 🌺 / Nhận Quà 🎁 / Sổ Ký Ức 📖

## ✨ Tính năng

- Viết tên lên bảng đen với hiệu ứng bụi phấn
- Đếm ngược đến ngày 20/11
- Lời chúc typewriter phong cách phấn (5 mẫu ngẫu nhiên)
- Hoa hồng đỏ CSS animation (không dùng ảnh)
- Hộp quà với pháo bông khi mở
- Canvas sổ ký ức ô ly — vẽ tay, lưu PNG
